**Оролт.** Эхний мөрөнд n, m (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5). Дараагийн m мөрөнд ирмэг u v (1 ≤ u, v ≤ n). Сүүлийн мөрөнд s, t.

**Гаралт.** Хамгийн богино замын ирмэгийн тоо; зам байхгүй бол -1.
