# Concept граф батлах асуулгын хуудас

**Хичээл:** Өгөгдлийн бүтэц ба алгоритм  **Семестр:** ____________
**Огноо:** ____________  **Багш:** ____________  **Судлаач:** ____________

---

## Энэ хуудасны зорилго

Оюутнуудын бодлого бодсон түүхээс мэдлэгийн төлөвийг загварчлахад **concept-уудын жагсаалт** болон **тэдгээрийн хоорондын холбоосууд** хэрэгтэй. Таны баталсан граф нь:
1. Загварт аль concept хооронд мэдээлэл дамжиж болохыг заана (edge mask).
2. Урьдчилан бүртгэсэн H1, H2 таамаглалын бүлгүүдийг тодорхойлно.

**Өгөгдөл цуглуулж эхэлсний дараа энэ графыг өөрчлөхгүй.** Хожим нэмсэн холбоос шинжилгээнд орохгүй. Тиймээс эргэлзээтэй холбоосыг "итгэл бага" гэж тэмдэглээд оруулах нь орхихоос дээр.

**Зарцуулах хугацаа:** ойролцоогоор 60–90 минут.

## 1-р хэсэг. Тодорхойлолтууд (эхлээд хамтдаа уншина)

| Нэр томьёо | Тодорхойлолт | Жишээ |
|---|---|---|
| **Concept** | Оюутан бие даан эзэмших, бодлогоор шалгагдах мэдлэгийн нэгж | "Stack", "BFS" |
| **PREREQUISITE (A → B)** | B-г **ойлгох эсвэл гүйцэтгэхэд A-гийн мэдлэг шууд шаардлагатай**. A-г мэдэхгүй оюутан B-г бүрэн эзэмших боломжгүй | Queue → BFS: BFS нь дарааллын үйлдлүүдийг шууд ашигладаг |
| **RELATED (A → B)** | A ба B холбоотой (ижил хэрэглээ, төстэй санаа), гэхдээ **A-гүйгээр B-г сурч болно** | Хоёр өөр эрэмбэлэх арга |
| **Холбоосгүй** | Нэг нь нөгөөдөө мэдэгдэхүйц нөлөөлдөггүй | |
| **Чиглэл** | Холбоос нь урьдчилсан мэдлэгээс (A) зорилтот concept (B) руу чиглэнэ | |

⚠️ **Анхаарах:** хичээлд заадаг **дараалал** prerequisite-ийг илэрхийлэхгүй. Жишээ нь Array → Linked List → Stack → Queue гэж заадаг ч Stack-ийг сурахад Linked List заавал шаардлагатай биш байж болно.

**Тохирсон тодорхойлолт:** ☐ Дээрх тодорхойлолтыг хүлээн зөвшөөрсөн ☐ Өөрчилсөн (доор бичнэ үү)
